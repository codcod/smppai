= Installation

{product} requires Python 3.10 or later (below 3.14) and depends only on
`typing-extensions` at runtime.

== From source

[source,bash]
----
git clone https://github.com/codcod/smppai.git
cd smppai

# Install with uv (recommended)
uv sync

# Or install with pip
pip install -e .
----

== Optional: uvloop

For a faster event loop on Linux/macOS, install the `fast` extra:

[source,bash]
----
pip install 'smppai[fast]'
# or
uv add 'smppai[fast]'
----

{product} never installs the loop itself; opt in explicitly in your application:

[source,python]
----
import uvloop

uvloop.run(main())
----

== Verifying the install

[source,bash]
----
uv run pytest
----

See <<testing,Testing>> for how to run the full suite, including integration tests
that spin up a real client/server pair.
